# Roadmap

## Completed in the current MVP

- Neo4j graph provider with an in-memory default.
- Production-oriented Neo4j schema, scoped persistence, batching, cleanup, and health checks.
- JGit working-tree, staged, and commit diff analysis.
- Spring REST/DI, JPA mappings, conservative HTTP/messaging detection, and
  `@ConfigurationProperties` binding nodes.

## Next milestones

- Richer rename/deletion symbol attribution and diff visualizations.
- Streamable HTTP transport with authentication and Origin validation guidance.
- Testcontainers integration tests and reproducible benchmarks.
- Incremental content-hash indexing and batch graph updates.
- Kotlin, C#, TypeScript, Python, and Go analyzers.
