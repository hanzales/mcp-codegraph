# Sample Commerce App

This Spring fixture demonstrates REST, constructor injection, JPA entities and
repositories, `@ConfigurationProperties`, and a minimum-order business rule.
Index it with MCP CodeGraph using `scan_project` and inspect `OrderController`,
`OrderService`, `Order`, `OrderRepository`, and `CommerceProperties`.

It is a static-analysis fixture; no database or external payment service is
required to demonstrate the graph relationships.
